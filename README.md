# 🚀 Nova - თანამედროვე და ადაპტური Landing Page

ეს პროექტი წარმოადგენს თანამედროვე, სრულად ადაპტურ და ვიზუალურად დახვეწილ Landing Page-ს, რომელიც შექმნილია სუფთა (Vanilla) **HTML5**, **CSS3** და **JavaScript (ES6+)** ტექნოლოგიებით.

## 🌟 ძირითადი ფუნქციონალი

1. **სემანტიკური და სუფთა კოდი**:
   - `index.html` აგებულია W3C სტანდარტების სრული დაცვით.
   - არ იყენებს მძიმე გარე ბიბლიოთეკებს (Bootstrap, Tailwind, jQuery და ა.შ.), რაც უზრუნველყოფს მყისიერ ჩატვირთვას.
2. **მოდერნისტული დიზაინი**:
   - Glassmorphism (მინისებრი ეფექტი), ბუნდოვანი ფონური ორბიტები (Floating Glow Orbs), გრადიენტული ტექსტები და მიკრო-ინტერაქციები.
3. **Features (3 ბარათი)**:
   - თითოეული ბარათი უზრუნველყოფილია Hover 3D ეფექტით, იკონებით და მკაფიო აღწერით.
4. **საკონტაქტო ფორმა რეალურ დროში ვალიდაციით**:
   - სახელის (მინ. 2 სიმბოლო), ელ-ფოსტის (RFC სტანდარტის რეგექსი) და შეტყობინების (მინ. 10 სიმბოლო) შემოწმება.
   - ანიმაციური Spinner და წარმატების Toast შეტყობინება.
5. **Theme Switcher**:
   - ღილაკზე ერთი კლიკით გადართვა Dark და Light რეჟიმებს შორის.
   - არჩეული თემის დამახსოვრება `localStorage`-ში.
6. **ადაპტურობა (Responsive Design)**:
   - იდეალურია ნებისმიერ ეკრანზე: სმარტფონებზე (iPhone/Android), პლანშეტებზე (iPad) და 4K ეკრანებზეც კი.
